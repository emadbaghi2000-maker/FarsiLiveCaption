# زیرنویس زنده فارسی — نمونه اولیه اندروید

این پروژه یک نمونه آزمایشی برای گوشی فرد ناشنواست: میکروفون گوشی را فعال می‌کند و گفتار فارسی را با سرویس تشخیص گفتار اندروید به متن تبدیل می‌کند. متن تشخیص‌داده‌شده با فونت درشت نمایش داده می‌شود.

## ساخت APK
1. Android Studio نسخه جدید را نصب کنید.
2. پوشه پروژه را باز کنید.
3. اجازه دهید Gradle همگام‌سازی شود و Android SDK 36 نصب شود.
4. گوشی را وصل کنید و Run بزنید، یا از مسیر **Build > Build APK(s)** خروجی APK بگیرید.
5. در گوشی مجوز میکروفون را بدهید و «شروع زیرنویس» را لمس کنید.

## آزمایش پیشنهادی
- ابتدا خارج از تماس، یک نفر فارسی صحبت کند تا تشخیص گفتار بررسی شود.
- سپس تماس معمولی برقرار کنید، بلندگوی گوشی ناشنوا را روشن کنید و دوباره آزمایش کنید.
- اگر متن متوقف شد یا خطای «میکروفون/سرویس مشغول است» ظاهر شد، این محدودیت هم‌زمانی میکروفون هنگام تماس است، نه لزوماً ایراد برنامه.

## محدودیت مهم
اندروید معمولاً اجازه نمی‌دهد برنامه‌های عادی صدای داخلی تماس تلفنی را مستقیماً ضبط کنند. این نمونه فقط از میکروفون گوشی استفاده می‌کند و موفقیت آن هنگام تماس به مدل گوشی، نسخه سیستم، برنامه تماس و سیاست صوتی سازنده بستگی دارد. بنابراین این پروژه **APK آماده و تأییدشده برای کار حین تماس نیست**؛ ابتدا باید روی مدل واقعی گوشی آزمایش شود. برای عملکرد قابل اتکا ممکن است لازم باشد از یک برنامه تماس اینترنتی سازگار یا دستگاه/میکروفون جداگانه استفاده شود.

## حریم خصوصی
این نمونه از Android SpeechRecognizer استفاده می‌کند. بسته به سرویس تشخیص گفتار نصب‌شده، پردازش ممکن است از طریق اینترنت و سرویس ارائه‌دهنده انجام شود. برای مکالمات حساس، پیش از استفاده سیاست حریم خصوصی سرویس را بررسی کنید.
